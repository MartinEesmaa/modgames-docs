## Modding the game

**SMB1R:**

See the above note, I edited the sprite using Aseprite of PNG files and also manual edit of JSON files which may be difficult. Please note sprites must have transparent background of Super Mario Bros 1 Remastered.

Recommendation: The probably easy way is to add your own custom character for template tool on GameBanana without JSON: <https://gamebanana.com/tools/20733> (credit: Casteor573)

### Installing mod games

It's pretty simple to install mod files on game.

**SMB1R:**

Remember, you must have own original legal copy of Super Mario Bros 1 of NES to play remastered game, see the FAQ: <https://github.com/JHDev2006/Super-Mario-Bros.-Remastered-Public/wiki/Frequently-Asked-Questions>

On Super Mario Bros 1 Remastered of custom characters, please go to [SMB1R/custom_characters](SMB1R/custom_characters/) folder. Copy Martin folder of custom_characters into your local data of the game SMB1R.

```text
Windows: %APPDATA%\SMB1R
Mac: ~/Library/Application Support/SMB1R
Linux: ~/.local/share/SMB1R
```

Place the folder you extracted into your custom_characters folder.

For more information, see the wiki: <https://github.com/JHDev2006/Super-Mario-Bros.-Remastered-Public/wiki/Custom-Characters>
