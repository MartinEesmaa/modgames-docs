# Telltale games

Telltale games produces adventure stories games interactive.

It uses archives to store data, music, textures and so on...

| Data category type | File type format |
| --- | --- |
| Textures | .d3dtx |
| Models mesh | .d3dmesh |

## Explore

If you want to explore the files of archives files, here are softwares that you can decompress from ttarch file to folder from any software can be done using:

- [Telltale TTARCH files extractor/rebuilder 0.3.2 (ttarchext)](https://aluigi.altervista.org/papers.htm#others-file)
- [TTG-Tools](https://github.com/HeitorSpectre/TTG-Tools)
- [Telltale D3DMesh Editor](https://github.com/HeitorSpectre/Telltale-D3DMesh-Editor)

### Modding the game

Please note some games may be not supported for replacing 3D models by own models for lack of support or might corrupt.

### Installing mod games

It's pretty simple to install mod files on game.

For example on Minecraft Story Mode Season 1, updated unpacked files like d3dmesh, d3dtx and so on has to be on Archives folder order to play work well.
